# CME538 - Introduction to Data Science for Civil & Mineral Engineers

## Fall 2026

### Lectures

Lecture directories contain the available slides, notebooks, datasets, code-along materials, and recordings for each week.

| Week | General Focus | Contents |
|---|---|---|
| [Week 1](./week1/) | Introduction and Python foundations | The data science landscape, engineering applications, the data science toolbox, and a Python basics review. |
| [Week 2](./week2/) | Pandas | DataFrames, importing data, selection, grouping, aggregation, iteration, joins, and a Titanic code-along. |
| [Week 3](./week3/) | Exploratory analysis and data preparation | Exploratory data analysis, importing delimited and hierarchical formats, unstructured data, and data cleaning. |
| [Week 4](./week4/) | Text, datetimes, and visualization | String and datetime processing, time resampling, visual encodings, scales, conditioning, and perception. |
| [Week 5](./week5/) | Storytelling and structured data contexts | Data storytelling, time-series analysis, geospatial data, and an introduction to machine learning. |
| [Week 6](./week6/) | Optimization | Loss functions, absolute and squared loss, gradient descent, feature scaling, and stochastic gradient descent. |
| [Week 7](./week7/) | Regression and generalization | Linear regression, model evaluation, feature engineering, categorical encoding, transformations, and generalization. |
| [Week 8](./week8/) | Classification | Logistic regression, classification loss, decision thresholds, evaluation metrics, cross-validation, and class imbalance. |
| [Week 9](./week9/) | Model diagnosis and selection | Bias and variance, underfitting and overfitting, regularization, feature selection, and hyperparameter tuning. |
| [Week 10](./week10/) | Unsupervised learning and tree models | Principal component analysis, K-means and hierarchical clustering, decision trees, and random forests. |
