# Teaching data

- `nba.csv`: course-local 2017–2018 NBA regular-season box scores. The file contains 2,460 team rows from 1,230 games. Each game has two dependent rows. These final box scores support retrospective classification, not a pre-game forecast. Source: https://www.nba.com/stats/
- Iris: bundled scikit-learn flower dataset, https://scikit-learn.org/stable/datasets/toy_dataset.html#iris-dataset .
- `classification_animals.png`: generated teaching illustrations. Labels and scores are deliberately assigned examples, not image-model predictions.
- The larger photograph grid uses the real images and licences listed in `animal_photos/ATTRIBUTION.md`.
