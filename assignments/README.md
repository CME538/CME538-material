# CME538 - Introduction to Data Science for Civil & Mineral Engineers

## Fall 2026

### Assignments

Each assignment directory contains a student notebook and the data or supporting files required for the work.

| Assignment | General Focus | Contents |
|---|---|---|
| [Assignment 1](./assignment1/) | Pandas fundamentals and tabular data analysis | San Francisco salaries and wine-review datasets; loading, inspection, summary statistics, filtering, and aggregation. |
| [Assignment 2](./assignment2/) | Data wrangling and parsing | HTML parsing, file metadata, NOAA wave-data files, data combination, and supporting utilities. |
| [Assignment 3](./assignment3/) | Data cleaning and text analysis | JSON tweet data, timestamp and device analysis, text processing, and sentiment analysis with the VADER lexicon. |
| [Assignment 4](./assignment4/) | Exploratory data analysis | Toronto Bike Share and weather data; time-series preparation, visualization, distributions, and relationship exploration. |
| [Assignment 5](./assignment5/) | Geospatial analysis | Toronto neighbourhoods, bikeways, subway stations, and bike-share stations; GeoDataFrames, coordinate systems, overlays, and spatial relationships. |
| [Assignment 6](./assignment6/) | Linear regression | Ames housing data; exploratory analysis, feature engineering, model fitting, prediction, and evaluation. |
| [Assignment 7](./assignment7/) | Email spam classification | Email cleaning, word-based feature engineering, classifier training, and precision-recall evaluation. |
| [Assignment 8](./assignment8/) | The data science life cycle | New York City taxi data; selection, cleaning, exploratory analysis, geospatial filtering, feature engineering, and trip-duration prediction. |
| [Assignment 9](./assignment9/) | Unsupervised learning | Principal component analysis and clustering using 3D data, bicycle-traffic patterns, and colour data. |
